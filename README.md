# Libft, Égalité, Fraternité

Un manuel interactif et pédagogique des fonctions C, basé sur une archive Libft de l'École 42 et ouvert aux fonctions cousines de la libc/POSIX/BSD.

- Site statique en HTML, CSS et JavaScript vanilla, sans dépendance externe.
- Fiches avec prototypes, fonctionnement, résultats, pièges et exemples.
- Distinction explicite entre fonctions présentes dans la Libft de référence et fonctions complémentaires.
- Identité visuelle bleu pastel et navigation responsive.
- Aucun sujet officiel 42 reproduit.

Ouvrir `index.html` localement dans le navigateur, ou publier le dossier racine avec GitHub Pages.

## Limites

Ce site est un support pédagogique. Les comportements non définis et les différences entre normes sont explicités lorsqu'ils sont importants. Les fiches se réfèrent à l'interface définie dans `libft.h`, sans prétendre certifier toutes les implémentations.
